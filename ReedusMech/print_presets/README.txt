================================================

Install (pick one method):

A) File -> Import -> Import Configs
   Select BOTH json files in this folder, then restart Bambu Studio.

B) Manual copy (if import does nothing)
   Copy into:
   C:\Users\DaniS\AppData\Roaming\BambuStudio\user\734615489\process\
   C:\Users\DaniS\AppData\Roaming\BambuStudio\user\734615489\filament\
   Restart Bambu Studio.

After restart, select:
  Process  = Reedus TPU Tire 0.20 @BBL X2D
  Filament = Generic TPU Reedus Slow @BBL X2D

Re-slice -> Preview -> Color scheme Speed.
Tread blocks should show ~18-20 mm/s (blue/purple), not 50 mm/s green.
